# 真实招聘数据爬虫使用指南

## 📋 概述

本系统支持从真实招聘网站（Boss直聘、拉勾网、猎聘）爬取岗位数据，使用 Puppeteer 无头浏览器，需要先登录才能爬取。

## 🚀 快速开始

### 第一步：登录招聘平台

在终端运行以下命令登录（会打开浏览器窗口）：

```bash
# 登录 Boss 直聘
npm run login:boss

# 登录拉勾网
npm run login:lagou

# 登录猎聘
npm run login:liepin
```

**登录流程：**
1. 浏览器会自动打开登录页面
2. 手动登录（支持手机号+验证码、微信扫码等）
3. 登录成功后，在终端按 **回车键**
4. 登录状态会自动保存到 `auth-state.json` 文件

### 第二步：爬取数据

#### 方式 1：使用命令行

```bash
# 爬取 Boss 直聘数据
npm run crawl:jobs
```

#### 方式 2：使用 Web 界面

访问应用的 **设置页面**，在"真实招聘数据爬取"区域：
1. 选择平台（Boss直聘/拉勾网/猎聘）
2. 配置搜索关键词（逗号分隔）
3. 配置城市（逗号分隔）
4. 点击"开始爬取真实数据"按钮

## 🔧 配置说明

### 爬虫配置

在 `lib/crawlers/index.ts` 中修改配置：

```typescript
const CRAWL_CONFIG = {
  platform: "boss" as "boss" | "lagou" | "liepin",  // 爬取平台
  keywords: ["前端开发工程师", "React开发工程师", "Vue开发工程师"],  // 关键词
  cities: ["北京", "上海", "深圳", "杭州"],  // 城市
  industrySlug: "frontend",  // 行业
  headless: true,  // 是否隐藏浏览器窗口
};
```

### 登录状态

- 登录状态保存在项目根目录的 `auth-state.json` 文件
- 包含 cookies 信息，下次爬取时自动使用
- 如果登录失效，重新运行登录命令即可

## 📊 数据导入流程

1. **爬取数据** - 从招聘网站获取岗位列表
2. **数据清洗** - 提取岗位名称、公司、薪资、技能等
3. **去重处理** - 基于 URL hash 避免重复
4. **导入数据库** - 自动插入 Supabase 数据库
5. **关联行业** - 自动关联到对应的行业 ID

## ⚠️ 注意事项

### 反爬虫策略

1. **登录要求** - 必须先登录才能查看和爬取数据
2. **请求频率** - 建议设置合理的爬取间隔（默认 3 秒）
3. **IP 限制** - 避免频繁请求，可能被限制
4. **验证码** - 如果触发验证码，需要手动处理

### 登录状态维护

- 登录状态会过期，需要定期重新登录
- 如果爬取失败，先检查登录状态是否有效
- 可以删除 `auth-state.json` 重新登录

### 数据质量

- 爬取的是真实网站的实时数据
- CSS 选择器可能需要随网站更新而调整
- 建议定期检查爬取结果

## 🐛 常见问题

### 1. 爬取不到数据

**原因：**
- 未登录或登录状态已过期
- 触发了反爬虫机制
- 网络问题

**解决：**
- 重新运行登录命令
- 检查 `auth-state.json` 是否存在
- 等待一段时间后重试

### 2. 浏览器无法打开

**原因：**
- Puppeteer 未正确安装
- 缺少 Chrome/Chromium 浏览器

**解决：**
```bash
# 重新安装 Puppeteer
npm install puppeteer
```

### 3. 数据导入失败

**原因：**
- Supabase 连接失败
- 数据库表不存在

**解决：**
- 检查 `.env.local` 中的 Supabase 配置
- 确认数据库表结构已创建

## 🔐 安全建议

1. **保护登录状态** - `auth-state.json` 包含敏感信息，不要提交到 Git
2. **定期更新** - 定期重新登录，确保状态有效
3. **合理爬取** - 避免频繁请求，遵守网站规则
